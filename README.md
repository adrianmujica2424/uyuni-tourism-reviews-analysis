# Uyuni Tourism Reviews Analysis

Proyecto personal de análisis de reseñas de atracciones turísticas de
Uyuni (Bolivia): Salar de Uyuni, Isla Incahuasi, Laguna Colorada y otros.

## Qué hace
- Consulta la Tripadvisor Content API oficial para obtener reseñas
  de atracciones turísticas.
- Normaliza, valida y resume los datos (calificaciones, fechas, lugares).
- Respeta los límites de cuota y los términos de uso de la API.

## Uso de los datos
- Los datos se usan solo para análisis personal y educativo.
- No se redistribuyen las reseñas. Se atribuye el contenido a Tripadvisor.
- La clave de API nunca se publica en este repositorio.
